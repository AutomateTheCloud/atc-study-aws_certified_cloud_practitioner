# The CLF-C02 exam at a glance

The AWS Certified Cloud Practitioner exam, version CLF-C02, in tables. Every fact was checked on **2026-10-23** on the AWS page linked beside it. AWS changes these details; **check the live pages before you book.**

**For:** anyone planning to take the exam. Look things up here; the teaching is in the modules.

## Format and scoring

| Item | As of 2026-10-23 | Source |
|---|---|---|
| Exam code and level | CLF-C02, Foundational | [Exam page](https://aws.amazon.com/certification/certified-cloud-practitioner/) |
| Questions | 65: 50 scored and 15 **unscored** (new questions AWS is trying out). You can't tell which are which, so answer every one | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Question types | **Multiple choice:** one correct answer out of four. **Multiple response:** two or more correct answers out of five or more | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Time | 90 minutes | [Exam page](https://aws.amazon.com/certification/certified-cloud-practitioner/) |
| Extra time in English | Non-native English speakers taking the exam in English can request 30 more minutes (ESL +30). Request it once, before you register | [Before testing](https://aws.amazon.com/certification/policies/before-testing/) |
| Scoring | Pass or fail, on a **scaled score** from 100 to 1,000 (a score adjusted so different versions of the exam are equally hard to pass). The pass mark is **700** | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Passing overall | **Compensatory:** you pass on your total, not domain by domain | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Guessing | An unanswered question counts as wrong. There is no penalty for a wrong guess | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Hands-on tasks | None. Only the two question types above. You don't build anything during the exam | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Results | Within 5 business days, in your AWS Certification Account. A score report may rate each section; AWS advises caution in reading it | [After testing](https://aws.amazon.com/certification/policies/after-testing/); [exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |

## Retakes and validity

| Item | As of 2026-10-23 | Source |
|---|---|---|
| If you fail | Wait 14 days, then retake. No limit on attempts; each costs the full price | [After testing](https://aws.amazon.com/certification/policies/after-testing/) |

## What the exam tests, and where this guide covers it

The exam guide splits the exam into four **domains** (subject areas) and 19 **task statements** (the specific things each domain tests). The weights below have been the same in every CLF-C02 exam guide version we checked.

![Horizontal bar chart of the four domain weights: Domain 1 Cloud Concepts 24%, about 12 scored questions; Domain 2 Security and Compliance 30%, about 15; Domain 3 Cloud Technology and Services 34%, about 17; Domain 4 Billing, Pricing, and Support 12%, about 6.](../../images/00-03-domain-weights.svg)

*Notice that Domains 2 and 3 together are 64% of the exam. Domain 3 lists the most services, but each of its eight task statements gets only about two questions. Question counts are our arithmetic (weight × 50 scored questions), not AWS's figures; each exam form varies.*

## What the exam doesn't test

| Not tested | Source |
|---|---|
| Writing code | [Exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html), target candidate |
| Designing cloud architecture | Same |
| Troubleshooting | Same |
| Implementation | Same |
| Load and performance testing | Same |

The exam asks which service or idea fits a situation, not how to build or fix it. This guide's labs go beyond the exam on purpose: doing a task makes the ideas concrete.

## When the exam changes

| Item | As of 2026-10-23 | Source |
|---|---|---|
| Revisions to the exam guide | AWS revised the guide in 2026 (support plan names, some service names, some services removed) and kept the code CLF-C02. We can't confirm from which date live exam questions use the new wording, so learn both old and new names ([AWS changes fast](04-aws-changes-fast.md)) | Archived copies of the [exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) |
| Notice of changes | AWS says guide revisions are published at least one month before the exam changes | [Certification FAQs](https://aws.amazon.com/certification/faqs/) |
| New services | A new service or feature must be generally available for 3 months before it can appear on an exam | [Certification FAQs](https://aws.amazon.com/certification/faqs/) |
| A successor exam | None announced | [Exam guides index](https://docs.aws.amazon.com/aws-certification/latest/examguides/aws-certification-exam-guides.html) |

## Exam content is confidential

| Rule | Source |
|---|---|
| You agree to keep exam questions confidential, and not to share them | [AWS Certification Program Agreement](https://aws.amazon.com/certification/certification-agreement/) |
| Having or using exam questions shared without AWS's permission, such as "real exam questions" posted online, breaks the agreement | Same |
| AWS can cancel results and revoke a certification, even after it was issued | Same |
