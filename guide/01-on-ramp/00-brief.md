# Module 01: Explain how one online order travels from a customer's phone to the bakery's records, and how it stays safe

This optional module teaches the IT basics the AWS modules use without explaining: servers, networks, data, data centers, APIs and everyday security. Each lesson starts with a short test, so you can skip what you already know.

**For:** an adult studying alone, new to IT, who wants to understand AWS and use it safely. You chose the on-ramp path in [Welcome](../00-start-here/01-welcome.md). **Time:** about 1.5 hours if you read every lesson, less for each one you test out of. You need no AWS account.

## The scenario

A small bakery takes orders for pickup through its own website, which runs on three servers in a room behind the shop. The owner is thinking about the cloud (Module 02), but first asks: **"When a customer orders a cake on their phone, what actually happens, and how is it kept safe?"** By the end you can answer in plain words. The bakery is made up, and the later modules use it too.

| **01.03a** Explain how a database differs from a file, and which one fits a kind of data | 01.03 |
| **01.04a** Explain what a data center is and how virtualization turns one physical server into many | 01.04 |

| **01.05b** Read a short JSON document | 01.05 |
| **01.06a** Explain how passwords, MFA, encryption and least privilege each protect an account or its data | 01.06 |

## What this covers on the exam

No exam task directly: the [CLF-C02 exam guide](https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html) doesn't test these basics on their own, and AWS says the exam suits people without an IT background ([exam page](https://aws.amazon.com/certification/certified-cloud-practitioner/), checked 2026-10-24). But the AWS modules and the exam use these words constantly.

## How the module is laid out

**Lessons** (about 15 minutes each):

1. [Computers and servers](01-computers-and-servers.md)
2. [Networks, IP addresses, DNS and HTTPS](02-networks-ip-dns-https.md)
3. [Files vs databases](03-files-vs-databases.md)
4. [Data centers and virtualization](04-data-centers-and-virtualization.md)
5. [APIs, the command line and JSON](05-apis-command-line-and-json.md)
6. [Everyday security: passwords, MFA, encryption and least privilege](06-everyday-security.md)

**Test-outs instead of a check.** Each lesson opens with "Test out: do you already know this?". Answer without looking anything up. If every answer is right and none was a guess, skip to the next lesson; otherwise read the lesson, then try the test-out again. Count a lucky guess as wrong. There is no separate end-of-module check.

**Hands-on:** none. You open an AWS account later, in the [guardrails primer](https://github.com/AutomateTheCloud/atc-study-aws_account_guardrails/blob/main/primer/00-read-this-first.md), before Lab 01 in Module 02.
