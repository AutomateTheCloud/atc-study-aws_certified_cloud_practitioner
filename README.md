# Automate the Cloud Study Guide for the AWS Certified Cloud Practitioner (CLF-C02) Exam

A study guide that teaches the skills behind the AWS Certified Cloud
Practitioner certification, exam version CLF-C02. Passing the exam is the
goal; understanding the cloud properly is the point. It is written for
self-paced learners, including people new to IT, and explains why things
work the way they do, not only what to memorize.

**Status:** in development. Nothing here is published yet.

## Editions

The guide is written once, in Markdown, and built into three editions:

- **Markdown** in this repository, readable on the hosting platform.
- **Website**, as a multi-page course on an Automate the Cloud learning site.
- **PDF**, as a book-style edition.

Hands-on labs run in the learner's own AWS account, with cost guardrails
set up before anything else. Where a real lab would cost money or carry risk,
the guide simulates it instead.
